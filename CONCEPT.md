# AntiChaos — Feed-First Self-Development OS

## Візія

**AntiChaos** — це особистий штаб для людей, яким важко систематизувати життя. Це не просто планер і не просто трекер звичок. Це екосистема саморозвитку, де все пов'язане: задачі, звички, щоденник, знання та AI-психолог працюють разом, щоб допомогти користувачеві перейти від хаосу до структури.

**Target audience:** Люди 20-45 років, які хочуть змінити життя, але тонуть у хаосі думок, прокрастинації та відсутності системи. Це не корпоративні менеджери — це творчі люди, підприємці, фрілансери, студенти, всі хто шукає баланс і розвиток.

---

## Філософія Продукту

### 1. Хаос — це нормально
Ми не змушуємо користувача бути ідеальним. Ми приймаємо хаос як точку відліку і допомагаємо поступово будувати структуру.

### 2. Швидкий захват > досконала організація
Людина в хаосі не хоче заповнювати форми. Вона хоче написати "треба зробити X, нагадати про Y, думка про Z" і щоб система сама все розклала по полицях.

### 3. AI як психолог, а не як помічник
AI не просто парсить текст — він розпізнає емоційний стан, пропонує техніки стабілізації, дає контекстні поради на основі патернів поведінки.

### 4. Знання → Практика → Результат
Користувач читає книгу/цитату/методику → створює звичку або задачу → бачить прогрес. Все пов'язане в один цикл.

### 5. Гнучкість > жорстка структура
Daily anchors, звички, задачі — все налаштовується під графік і стан користувача. Жодного "ти повинен". Тільки "що тобі зараз допоможе?".

### 6. Один скрол — усе видно
Feed-first архітектура: головний екран = вертикальна стрічка з блоками всіх розділів. Ніяких вкладок, де щось ховається. Новий розділ = новий блок вище в стрічці.

## Feed-First Архітектура

### Головний Екран = Smart Feed
Вертикальний скрол з блоками. Кожен блок — це розділ додатку, який показує актуальний контент inline. Тач по блоку → повний перегляд секції.

**Порядок блоків (за замовчуванням):**
1. 🏠 Привітання + настрій
2. 🎯 Фокус дня (Tasks)
3. ⚓ Наступний якір
4. 🔁 Звички сьогодні
5. 🧘 Практика дня (Practicum)
6. 💡 Цитата/Інсайт (Library)
7. 📝 Щоденник промпт
8. 🎲 Random Action (нова фішка!)
9. 🧠 Коуч чек-ін

### Логіка блоків:
- **Адаптивні:** показуються залежно від часу доби, настрою, активності
- **Пріоритетні:** нові розділи додаються вище в стрічці для привернення уваги
- **Інтерактивні:** можна виконати дію прямо в блоку (відмітити звичку, підтвердити настрій)

### Навігація (мінімалістична):
Bottom bar: `[Штаб] [Коуч Чат] [Меню ☰]`

Все інше доступно через тачку на блоках або меню.

## Розділи Додатку (9 Модулів)

### 🏠 1. Привітання + Настрій
- Time-aware greeting: "Ранок, [ім'я]" / "Вечір"
- Mood check: 3-5 емоційних кнопок (😊 😐 😔 😰 🔥)
- Зберігається в user_state_logs для паттерн-детекції
- Тон: спокійний, підтримуючий

### ✅ 2. Tasks / Задачі
Feed показує:
- "Фокус дня": 1-3 пріоритетні задачі
- Quick add кнопка (+) з NLP парсингом

Повний перегляд включає:
- Фільтри: Сьогодні / Цього тижня / Всі / Перевантажені
- Рівень енергії: 🟢 легко / 🟡 середньо / 🔴 важко
- Розбиття на кроки (AI-assisted)
- Статуси: Нове → В процесі → Зроблено (тільки три!)
- "Пропустив? Перенесемо без докорів"

### ⚓ 3. Anchors / Якіри Дня
Feed показує:
- Наступний якір з countdown ("Через 20 хв — ранкове HQ")

Налаштування (Settings):
- Кастомні якірні моменти дня: ранок, фокус-блок, вечірній огляд тощо

### 🔁 4. Habits / Звички
Feed показує:
- Горизонтальний скрол сьогоднішніх звичок з чекбоксами
- Один тап = виконано

Повний перегляд включає:
- Всі активні звички
- Habit Level (0-5 зірок) замість streaks — без сорому за пропуски
- Календар візуалізації (зелений = зроблено, порожній = пропущено, БЕЗ червоного)
- Мікро-звички: "Сьогодні важко? Зроби мінімум"
- Рівні складності: легка/середня/важка

### 🧘 5. Practicum / Практикум (НОВИЙ!)
Feed показує:
- "Практика дня", підібрана AI на основі настрою/часу/енергії
- Приклад: "Ти тривожний сьогодні — спробуй Box Breathing (2 хв)"

Повний перегляд включає категорії:
- **Дихальні:** 4-7-8, Box breathing, Когерентне дихання, Вілька капала
- **Заземлення:** 5-4-3-2-1, Сканування тіла, Холодна вода на руки
- **Тілесні:** Розтяжка для спини (для сидячих), Прогресивна релаксація, 5 хв руху
- **Ментальні:** Медитація уваги (3/10 хв), Візуалізація дня, Переформулювання думок
- **Емоційні:** "Назвай емоцію", Лист до себе, Техніка "А що якщо?"
- **Духовні/Сенсові:** 3 речі за які вдячний, Що для тебе важливо зараз?, Зв'язок з природою

Кожна практика має:
- Таймер вбудований
- Крок-за-кроком інструкції
- "Зробити звичкою" кнопка → створює звичку в Habits секції

### 📚 6. Library / Бібліотека ("Інструменти")
Feed показує:
- Цитата дня АБО AI інсайт з даних користувача
- Приклад: "Ти найпродуктивніший о 10 ранку — плануй важливе тоді"

Повний перегляд включає (мінімалістично):
- **Методології:** Pomodoro, тайм-блокінг, GTD-lite — коротко з прикладами
- **Цитати:** 20-30 потужних цитат за темами (мотивація, дисципліна, тривога, фокус)
- **Вижимки книг:** Ключові ідеї + вправи з self-dev книг (НЕ резюме, інструменти!)
- "Застосувати на практиці" кнопка → створює звичку/задачу

### 📝 7. Journal / Щоденник
Feed показує:
- Контекстний промпт за часом доби:
  - Ранок: "Що в голові зараз?"
  - Вечір: "Швидкий огляд дня: що пішло добре?"

Повний перегляд включає:
- Free write — просто пиши, без шаблонів
- Morning Pages — 3 хв потокового письма вранці
- Evening Review — структуровано: добре / складно / навчився / оцінка дня (1-5)
- Трекер настрою та енергії з часом
- AI weekly summaries: "Я помітив, ти часто пишеш про X"
- Пошук по записах

### 🎲 8. Random Action / Рандомна Дія (НОВА ФІШКА!)
Feed показує:
- Картка з рандомною конструктивною дією + кнопка "Реролл"

Приклади дій:
- "Зроби 10 віджимань прямо зараз"
- "Напиши другу, яким ти його цінуєш"
- "Вийди на балкон і подихай 3 рази глибоко"
- "Запиши одну річ, яку ти зробив добре сьогодні"
- "Зроби розтяжку шиї — 20 сек вліво, 20 сек вправо"
- "Пий склянку води прямо зараз"
- "Подякуй собі за те що ти вже зробив цього тижня"

Логіка:
- Кнопка "🎲 Реролл" — генерує нову дію
- Можна відмітити як виконане → зберігається в статистиці
- Дії підбираються за контекстом (енергія, час доби, настрій)

### 🧠 9. Coach / AI Психолог
Feed показує:
- Чек-ін промпт: "Щось турбує? Можу допомогти" або ситуаційне повідомлення

Повний перегляд (чат інтерфейс):
- Пиши як другу/терапевту — без формальностей
- Emotion detection з тексту → підбір технік
- Швидкі сценарії: тривога / прокрастинація / вигорання / самотність / злість
- Weekly insights на основі journal + mood даних
- Emergency mode кнопка → миттєва техніка для паніки/тривоги/злості
- Працює офлайн (rule-based) або з OpenAI (опціонально, глибші відповіді)

## Cross-Section Connections ("Швейцарський Ніж" Ефект)

| Ситуація | Потік між розділами |
|----------|----------------------|
| Панічна атака | Coach → Emergency help → Practicum (Box breathing з таймером) → Journal ("запиши що сталося") |
| Прокрастинація | Tasks block → "Це лякає?" → Coach ("розбити на кроки?") → Tasks (створено підкроки) → Practicum ("2 хв фокус-дихання перед стартом") |
| Вигорання | Feed помітив низький настрій 3 дні поспіль → пропонує легший день → Tasks (прибирає неважливі задачі) + Practicum (медитація відпочинку) |
| Новорічна мета | Coach ("що хочеш змінити?") → Tasks/Habits створено + Journal (трекер прогресу) + Practicum (техніки для мотивації) |
| Поганий сон | Greeting block запитує "як спався сон?" → Coach пояснює чому так може бути → Practicum (4-7-8 на ніч) → Habits (нова звичка: дихання перед сном) |

## Ключові Відмінності від Конкурентів

**Що інші роблять погано:**
- Habitica/Duolingo — занадто ігрово, дорослим незручно
- Notion/Obsidian — занадто гнучкі, треба самому все налаштовувати (хаос для хаотичних людей)
- Day One/Journey — гарні щоденники, але без зв'язку з продуктивністю
- Todoist/Things 3 — чудові to-do, але нуль емоційного інтелекту
- Calm/Headspace — круті практики, але відокремлені від життя

**Наша унікальність:**
1. **Екосистема, не набір фішок** — все пов'язане, все знає про все
2. **Емоційний інтелект** — додаток розуміє коли ти втомлений/злий/тривожний і адаптується
3. **Практика > теорія** — не просто "треба медитувати", а одразу таймер + техніка
4. **Без сорому** — пропустив день? нічого страшного, почнемо з малого

## Технічна Архітектура

- Offline-first: все працює без інтернету; AI — опціональний шар покращення
- Single-user app: без автентифікації, без cloud sync (поки що), все локально на пристрої
- Room database з 15+ таблиць для MVP + Practicum
- AI optional enhancement layer (OpenAI або rule-based fallback)
- Dark theme by default
- Ukrainian language UI
